# 1. STRICT Anti-"AI-Slop" Design System (CRITICAL)

1. **Zero Neon & Zero Cheap Gradients:**
   - Strictly FORBIDDEN: saturated purple/cyan/magenta gradients (`from-purple-500`, `to-blue-500`, neon glows, blurred colored background blobs, or heavy drop shadows).
   - **Dark Mode Palette (Default):** Deep architectural obsidian surfaces (`#09090B` main background, `#111113` elevated surface, `#18181B` interactive hover surface, `#FAFAFA` primary text, `#A1A1AA` muted text) with crisp `1px solid rgba(255, 255, 255, 0.08)` hairline structural dividers, subtle top inner highlights (`inset 0 1px 0 0 rgba(255, 255, 255, 0.06)`), and a `2.5%` opacity SVG matte film grain overlay.
   - **Light Mode Palette:** Warm studio alabaster (`#F8F8F7` background, `#FFFFFF` surface, `#F1F1EF` secondary surface, `#09090B` primary text, `#52525B` muted text) with `1px solid rgba(0, 0, 0, 0.08)` dividers.
2. **Zero Emojis & Zero Hand-Drawn Fake SVGs:**
   - Do NOT use a single emoji (no 🚀, 💻, ✨, 🤖, 🎵) anywhere in the UI or JSON data.
   - Load real official vector brand logos for all languages, frameworks, and OS platforms via **Devicon CDN** (`https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/{tech}/{tech}-original.svg`) and **SimpleIcons CDN** (`https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/{slug}.svg`) with an `onerror` fallback handler.
   - Use **Lucide Icons** (`1.5px` stroke width) for all UI system icons.
3. **Typography & Editorial Discipline:**
   - Load **Geist Sans** (or `'Inter'`) for UI/headings with tight tracking (`-0.03em`) and **Geist Mono** (or `'JetBrains Mono'`) for section index numbers (`01 // ARCHITECTURE`), tech tags, metrics, and terminal snippets.
